# CvO-Stundenplan

Eine App, die Stundenplan und Aktuelle Hinweise der CvO-GyO kombiniert. Sie wurde als Teil des Profilkursprojektes programmiert und danach weiterentwickelt. Mehr Informationen zur App gibt es auf der [Webseite](https://krintni.github.io/CvO-Stundenplan/).

Der Code folgt nicht immer den besten Praktiken, ist an einigen Stellen ungünstig umgesetzt und die Dokumentation ist nicht überall direkt ersichtlich. Trotzdem funktioniert die App und der Quellcode soll dabei helfen, die App zu verstehen, anzupassen oder einzelne Teile wiederzuverwenden.


Bei Fragen kann man sich gerne melden! Siehe [Kontakt](https://krintni.github.io/CvO-Stundenplan/contact.html).
